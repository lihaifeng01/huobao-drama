WHY

短剧公司的三个老问题，一个平台解决

短剧拼的是「出片速度 × 单集成本 × 质量稳定」。传统与零散的 AI 工具方案，都卡在这三点上。

① 流程割裂、人工搬运

写剧本用一个工具、生图用一个、生视频用一个、剪辑再用一个，素材来回导出导入，人为出错多、交接成本高。

② 角色 / 场景不一致

AI 出片最大的痛点：同一个角色每个镜头长得不一样，成片无法使用，只能反复重抽，烧钱烧时间。

③ 成本与团队不可控

多人共用 API Key，谁用了多少、哪个项目花了多少说不清；员工离职、项目交接数据难以管理。

一站式

6 个环节在同一个界面串成流水线，左侧进度栏实时标示当前阶段，新人上手即用。

一致性优先

先定妆角色 / 场景 / 道具，再用这些资产作为参考图注入每个分镜的视频生成，保证人物与场景前后统一。

模型自由、不被绑定

文本、图片、视频模型均可在界面一键切换，也可接入各类中转站，哪家便宜、哪家效果好就用哪家。

团队级管理

多账号、角色权限、项目成员、用量统计与积分分配，让老板看得清每一分钱花在哪里。

适合谁

短剧 / 漫剧制作公司、MCN 与内容工作室、小说 IP 方的视频化团队、需要批量产出竖屏剧情内容的电商与品牌方。

WORKFLOW

从小说到成片，六步走完

下面是真实的产品界面截图。

1创建项目

  • 选择画面比例：横屏 16:9 / 竖屏 9:16
  • 选择画面风格（3D / 真实感等），统一全片美术基调

2AI 剧本改写

  • 粘贴小说原文，AI 自动改写为拍摄剧本
  • 按集拆分，标注场景与角色
  • 改写结果可编辑并自动保存
  • 自动生成「前情摘要」，保证跨集剧情连贯

3资产提取与定妆

  • 一键提取角色 / 场景 / 道具，自动去重
  • AI 生成三视图形象，也可上传自有图片或参考图
  • 角色支持别名、合并重复、多套造型（服装 / 妆发）
  • 定妆后的设定被锁定，后续不会被覆盖

WORKFLOW

分镜、视频、拼接导出

把“镜头”变成“成片”的核心三步。

4分镜拆解

  • AI 按镜头节奏把剧本切成分镜序列
  • 自动生成每个分镜的视频提示词（含景别、运镜、时间段）
  • 提示词中 @角色名 自动关联参考图

5批量生成视频

  • 顶栏选择视频模型，分辨率与时长联动
  • 批量生成，失败任务一键重试
  • 每个分镜保留历史版本，可随时回滚或重绘
  • 可把上一镜尾帧作为下一镜首帧 / 参考图，镜头衔接更自然
  • 支持角色音色引用，人物声音前后一致

6拼接导出

  • 勾选镜头，FFmpeg 自动合成整集成片（已内置，无需另装）
  • 在线预览与下载
  • 可选识别语音生成字幕，压制字幕版成片
